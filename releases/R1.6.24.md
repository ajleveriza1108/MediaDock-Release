# MediaDock R1.6.24

License Activation Persistence Repair.

## Fixes

- Startup license validation, Enter Serial activation, and Release This Device are serialized through one process-wide license operation gate.
- An older startup validation can no longer finish later and erase a newly accepted activation.
- Activation still uses the existing protected-store write plus immediate read-back verification before success is returned.
- An isolated Credential Manager + current-user DPAPI persistence round-trip smoke test now runs before publication and does not touch the real customer activation.
- The licensed footer now refuses a Trial binding rebound while LicenseEntitlementState remains licensed.
- The licensed UI smoke explicitly simulates a Trial footer rebound and requires the visible footer to remain licensed.
- Shared BuildIdentity now resolves R1.6.24 and the updater self-test proves receipt of future R1.6.25.
- Existing Settings, strict 5+5 unlicensed trial, download engine, runtime tools, AppId, and per-user in-place installer identity are preserved.
