# MediaDock R1.6.22

Settings crash containment, compact zero-scroll Settings layout R1.8, and remaining visible mojibake repair.

## Fixes

- Settings window must pass a real runtime smoke test before release.
- Settings button failures are caught and logged instead of silently terminating MediaDock.
- Settings InitializeComponent failures are logged.
- Crash logs are written under LocalAppData\AJCoder\MediaDock\Logs.
- The risky R1.6.21 custom Settings scrollbar template is removed.
- Settings visible controls use clean ASCII text.
- The visible trial separator uses ASCII.
- Existing R1.6.21 features, licensing/trial state, in-place updater identity, and same installer AppId are preserved.
- R1.6.22 updater self-test proves receipt of future R1.6.23.
