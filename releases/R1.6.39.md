# MediaDock R1.6.39

## Repository Update

- Queue layout protection, visible Audio / Dub selection, rounded row actions, and the safe-delete dialog are included.
- M4A and FLAC download outputs are added alongside MP3.
- MP3, M4A, and FLAC share the existing audio trial counter.
- Optional clipboard media-link detection is disabled by default and never starts a download automatically.
- Windows Release build, engine contract tests, and startup smoke test passed before repository publication.
- Source publication uses a public-safe temporary clone, explicit changed-file allowlist, secret scan, remote-head recheck, and no force-push.

## Customer Channel

This repository update does **not** advance `latest-stable.json` or `latest-development.json` and does not create a customer installer release. Customer manifests remain unchanged until a separate installer finalization package uploads the R1.6.39 installer and verifies its SHA-256.
