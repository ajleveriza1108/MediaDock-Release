# MediaDock R1.6.23

Updater Detection + Build Identity Repair.

## Fixes

- Stable manifest requests now use a per-check cache-busting query.
- Stable manifest requests explicitly send Cache-Control no-cache/no-store and Pragma no-cache.
- Current MediaDock version resolution prefers the product informational version and safely falls back to assembly version.
- Updater log records current version, manifest version, stable flag, and candidate decision.
- Shared BuildIdentity now drives both the updater current version and the visible MediaDock version label.
- Release smoke test rejects a staged build whose visible footer is not MediaDock R1.6.23.
- Version parser accepts MediaDock R labels plus normal build metadata safely.
- Updater self-test proves R1.6.23 accepts a future R1.6.24 stable release and rejects same/inactive/foreign releases.
- Existing Settings, trial/licensing, download engine, runtime tools, AppId, and in-place installer identity are preserved.
