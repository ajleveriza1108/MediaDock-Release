# MediaDock R1.6.37

## Clip Range + Duration

- MediaDock now shows detected video duration in a dedicated Clip Range column instead of adding it to the title/source text.
- Set a start and end timestamp such as `00:05` to `02:37`; the selected section is honored for both MP4 and MP3 downloads.
- Invalid ranges are blocked while the queue item remains editable.

## Queue Controls

- Choose `Keep each item's format`, `All as MP4`, or `All as MP3` for ready queue items.
- Choose 1 through 5 simultaneous queue downloads; MediaDock never exceeds the hard maximum of 5.
- ETA has been removed from the customer download status because it was not sufficiently reliable. Percent, size, speed, and processing state remain available.

## Preserved Behavior

- Existing original-audio and YouTube dub selection behavior is preserved.
- Strict trial accounting continues to count the effective MP4/MP3 output type.
- Licensing, activation persistence, output folder, queue actions, and customer state remain preserved.
